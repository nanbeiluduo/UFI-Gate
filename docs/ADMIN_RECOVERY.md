# 管理员设备恢复与离线恢复密钥

## MAC 变化后登录

连接热点，打开 `http://热点网关:8090/`，点击「管理员登录」。输入 **UFI-Gate 管理员账号密码**，当前设备会被加入管理员设备列表并进入后台。该入口与访客上网账号认证相互独立。

服务通过热点接口的邻居表识别当前 MAC，不接受浏览器指定身份。只更新管理员访问权限，不自动清除设备封禁、配额或授予联网授权。旧管理员设备保留，可在后台单独移除。

非管理员仍无法访问 UFI-Gate 完整后台；认证开启时，原有 INPUT 规则继续限制 UFI-TOOLS 等网关服务。新增公开入口仅位于认证门户。获得管理设备权限不等于绕过 UFI-TOOLS 自身的登录验证。

## 首次注册与重新初始化

1. 插件提供 `setup.token` 临时初始化凭证，通过后台地址的 `#` 片段传递，有效期仍为 20 分钟。
2. 输入管理员账号、密码及初始化凭证。
3. 点击「下载恢复密钥 TXT」，妥善保存文件。
4. 勾选已确认保存，点击「完成并进入后台」。只有此时才提交账号、管理员设备和恢复密钥，并使初始化凭证失效。

下载步骤服务端校验；不能直接跳过下载调用完成接口。浏览器只能发起下载，不能证明文件已被永久保存，因此仍需用户确认。系统认证小窗口若不支持下载，应在正常浏览器中打开页面。

## 忘记密码

在门户「管理员登录」页面勾选「忘记密码，使用恢复密钥」，输入 TXT 中的密钥、新密码及确认密码。验证通过后，必须下载**新的**密钥并确认保存。

完成后，新密码、新密钥和当前管理员设备权限同时提交，旧密钥立即失效，全部旧后台登录会话注销。原管理员账号名、其他管理员设备和系统数据保留。

如果在完成前刷新、离开页面、服务重启或流程超时，原密码与原恢复密钥仍有效；重新发起流程并下载新的 TXT。未完成流程下载的密钥不能使用。每次准备流程有效期为 10 分钟，初始化同时受原 20 分钟凭证期限限制。

## 插件「重置初始化凭证」

确认后，通过现有本地 Root 控制通道清除管理员账号、密码、管理员设备权限、后台会话、旧恢复密钥及未完成恢复流程。设备记录、上网账号、配额、流量、联网授权与其他系统配置保留，不停服。

插件随后读取新的临时初始化凭证并打开后台，重新执行包含 TXT 下载的注册流程。若浏览器拦截新窗口，可使用插件显示的地址和凭证手动打开。

## 已安装用户升级

已有管理员账号无需重置。首次进入新版后台时，若没有恢复密钥，会要求生成、下载并确认保存。MAC 已变化的用户也可先从门户用原管理员账号登录，再补齐此步骤。

## 密钥与验证边界

- 密钥由系统密码学随机源生成，含 256 位随机数，以 `UFIG-` 加分组十六进制字符展示。它与程序更新签名密钥、初始化凭证不同。
- TXT 可离线保存。任何连入该热点、持有有效密钥的设备均可重置管理员密码，因此应将其视为管理员凭据，勿上传 GitHub 或发给访客。
- 设备仅持久化 SHA-256 校验摘要；待下载明文只保存在短时内存中，不写入状态文件、日志或通知。常规配置接口不返回摘要，也不接受覆盖该摘要。
- 下载票据绑定当前 MAC、IP、原管理员凭据和有效期，不能由另一设备使用。密码或密钥变更、Root 重置会使旧流程失效。
- 门户管理员验证采用独立全局限流：每分钟最多 12 次，连续 5 次凭据验证失败后限制 10 分钟，换 MAC/IP 不会重置该限制。
- 沿用现有本地 HTTP 部署；本次未加入 HTTPS，不能保证开放 WiFi 上管理员凭据的传输保密性。

## 开发验证

后端测试：`go test -mod=vendor ./...`，静态检查：`go vet -mod=vendor ./...`。

构建演示程序后运行 `node tests/recovery-ui-test.cjs`，并回归 `tests/management-ui-test.cjs`、`tests/update-ui-test.cjs` 和 `tests/ui-test.cjs`。浏览器测试只操作 `--demo` 服务，不测试真实防火墙。

真机需验证：MAC 变化后两个后台均拒绝访问、门户登录后恢复管理访问、保持其他访客受限、TXT 下载可用、旧密钥拒绝、新密钥重置成功，以及 Root 重置后设备数据和联网状态保留。
