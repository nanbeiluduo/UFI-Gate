# 自定义 Logo

进入管理后台的「门户外观」，分别选择：

- **网站 Logo**：显示在浏览器标签页、后台登录页和后台左侧品牌区域。
- **认证页 Logo**：替换访客认证页面顶部的 WiFi 图标，保持图片比例，支持透明背景。

选择文件后可预览，点击「保存设置」生效。「恢复默认」也需要保存。两个项目可分别设置，旧版配置无需迁移。

支持 PNG、JPG、GIF，单张最大 32 KiB，宽高均不超过 1024 像素。建议使用小尺寸透明 PNG。图片保存在设备的配置文件中，不依赖外部图床，因此未认证的访客也能看到 Logo。配置备份会包含图片。

这项更改需重新构建并安装插件后使用，仅修改源码不会更新已安装的设备。
