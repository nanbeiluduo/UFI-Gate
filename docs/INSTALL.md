# UFI-Gate 1.0.1

随身 WiFi 开放热点 + 网页认证插件。宿主：UFI-TOOLS `http-server-version` 设备端完整版；目标：Rooted ARM32 / ARM64 Android 随身 WiFi。

**这是带真实守护服务和防火墙实现的开发测试版，不是只有网页的演示。已通过本机逻辑与浏览器测试，但没有在 F50/U30 Air 等真机上完成网络栈验收。首次启用须保留 UFI Root Shell 或 ADB/su 恢复通道。**

## 文件

- `UFI-Gate-1.0.1-arm32.js` / `UFI-Gate-1.0.1-arm64.js`：直接导入宿主的安装插件，内嵌压缩后的静态 ARM32 / ARM64 Go 服务。安装不需联网下载运行时。
- `main.go / firewall.go / dns.go`：守护服务、API、认证、推送、防火墙和 DNS。
- `web/`：独立管理后台与认证页，Fluent / WinUI 3 视觉，支持浅色/深色和移动端。
- `service.sh`：常驻 supervisor、开机接入、停止与卸载。
- `emergency-recover.sh`：紧急网络恢复。
- `main_test.go / tests/ui-test.cjs`：逻辑与浏览器集成测试。
- `build.py / plugin.template.js / vendor/`：可离线复现构建所需源码；构建需要 Go 1.24 或更新版本。

## 实现与边界

| 功能 | 当前实现 |
|---|---|
| 独立后台 | `http://热点网关:8081/`；管理员登录、bcrypt cost 12、HttpOnly / SameSite 会话、闲置 30 分钟退出、5 次错误锁 10 分钟 |
| 数据大屏 | 5 秒刷新，当前活跃设备、上下行速率、今日/本月/累计用量、用量排行、待办审批、拦截包统计 |
| 设备 | MAC 识别、IP、尽力读取 DHCP 主机名、备注、放行、封禁、撤销会话、永久信任、解禁、重置统计、手动录入 MAC |
| 配额 | 自然日、历史总量、认证会话、固定天数周期；多种叠加；提前限速和满额断网/限速；默认模板；达到限额后保持限制，管理员解除 |
| 账号认证 | 独立上网账号，bcrypt 存储，可到期，会话不超过账号到期时间；支持账号绑定配额；设备配额可在 UI 编辑 |
| 图形验证码 | 本地 SVG，2 分钟有效、一次使用、5 次失败锁 10 分钟；适合低信任的公开网络 |
| 第三方人机验证 | hCaptcha、Turnstile、自定义兼容验证 API + 前端适配脚本；服务端校验，Secret 不发送给客户端。需要实际服务账户、允许的门户域名及依赖白名单，尚未完成真实服务联调 |
| 审批 | 访客申请、后台通过/拒绝、自动显示结果、请求合并、30 分钟有效 |
| 推送 | 企业微信 Markdown 审批链接、飞书交互卡片 URL 按钮、通用 Webhook、SMTP 邮件审批链接；支持测试发送、失败日志。未使用真实密钥验证送达 |
| 无认证拦截 | 在选定热点接口的 IPv4 FORWARD 默认拒绝；INPUT 仅放行门户、DNS、DHCP，管理保留 MAC 可访问原管理服务；HTTP 重定向，本地 DNS 门户应答 |
| IPv6 | 启用期间阻断该热点 IPv6，包括已认证设备，防止旁路；本版本提供 IPv4 上网 |
| 网址规则 | 精确域名、`*.example.com`、IPv4；黑名单优先，白名单免认证放行 TCP 80/443；本地 DNS + 动态解析 IPv4 规则。域名命中有日志 |
| 警告页 | 流量已满、设备封禁、网站禁止、审批等待/拒绝；文案、联系信息、主题色可配 |
| 生命周期 | 服务独立常驻、开机脚本、异常退出后清理并重启；宿主保存停用/删除插件后约 30 秒内自动恢复网络并退出 |

以下边界不能用前端 UI 或普通 iptables 规则消除：

1. **HTTPS / HSTS 无法像 HTTP 一样无证书警告地跳认证页或警告页。** 本插件不伪造站点证书：未认证的 HTTPS/QUIC/APP 外网流量会被阻断，认证通过系统“登录网络”入口、普通 HTTP 或本地门户完成。HTTP 探测被重定向有助于系统弹出认证窗口，但各系统是否弹窗需现场验证。
2. 域名黑名单是 DNS 与 IPv4 地址级的尽力过滤，不是完整的网址审计。加密 DNS/DoH、VPN/代理、缓存 IP 可能绕过已认证设备的域名规则；共享 CDN IP 可能导致连带拦截或白名单扩大。未认证设备仍受默认拒绝策略约束，只可连接明确放行的白名单 IP 的 80/443。要更严格限制可使用明确 IPv4 黑名单与有限的白名单，并另行部署能识别应用层协议的网关。
3. Rooted Android 固件可能有专有硬件 NAT、驱动加速或其他网络插件。程序会设置并回读 Android 标准 `tether_offload_disabled=1`，但不能证明厂商加速已被关闭。切换 OPEN 会重启热点；请用第二台非信任设备验证，发现绕过应立即停用并处理固件加速。单热点接口是当前支持范围，多接口/访客网络不能共用一套接口设置。
4. 同网段设备互访不一定经过网关 FORWARD；须在热点配置开启并验证 AP 隔离。MAC 随机化会被视为新设备，伪造已授权 MAC 仍是开放 WiFi 的身份边界；此插件不替代 WPA/802.1X 的链路身份验证。
5. 流量在所有 FORWARD 过滤规则之后、SNAT 之前的 POSTROUTING 阶段计数，按 IP 绑定映射到已经过 MAC 校验的设备，包含 IP 开销/重传，排除本地门户、DNS 与网关自身流量；只在准入规则启用期间记录，不回填安装前或关闭期间的用量；不应当作运营商计费账本。每 5 秒采样，配额可能超出一个采样窗口及规则更新期间的用量；异常掉电可能损失最后未保存的增量。
6. 限速使用 `hashlimit` 按字节丢包，上下行分别限制；是带宽上限控制，不是 tc 队列整形，突发/TCP 行为会影响实际速率。需内核支持字节型 hashlimit，安装前检测不通过会拒绝启用。
7. 远程审批需要设备的 `8081` 端口通过 VPN 或 HTTPS 隧道可达；运营商内网本地地址不能因发送邮件就从公网访问。审批链接 GET 只显示确认页，POST 才执行，避免邮件预取或机器人预览误放行。企业微信/飞书使用 URL 按钮或链接，不冒充无法配置的原生机器人回调。
8. 异常清理/停止后按 PRD 恢复原始准入，即“连上便能上网”。系统不自动覆盖原厂 WiFi 配置；热点的 OPEN/加密、SSID、AP 隔离等均由你在 UFI-Tools 宿主 WiFi 管理中自行维护，本插件不再代为改写。

## 安装顺序

### 安装包架构选择

在 UFI Root Shell 运行 `uname -m`，按当前系统执行架构选择：

| 输出 | 下载文件 |
| --- | --- |
| `armv7l` / `armv8l` | `UFI-Gate-1.0.1-arm32.js` |
| `aarch64` / `arm64` | `UFI-Gate-1.0.1-arm64.js` |

ARM32 使用 `GOARCH=arm GOARM=7,softfloat CGO_ENABLED=0`，不依赖设备的动态链接器或硬浮点支持；要求 ARMv7 或更高的 32 位执行环境。`armv8l` 应选择 ARM32 包，不能通过跳过架构检测运行 ARM64 二进制。其他架构会在写入服务前被拒绝。

只保留一个 UFI-Gate 插件：删除旧插件条目后导入对应的新包，保存并刷新，再检测环境并安装 / 更新服务。若旧服务正在运行，更新会暂时恢复网络并关闭认证，完成后需检查配置并重新开启。已有 `/data/ufi-gate` 状态和流量历史保留；不要删除状态目录。


1. 使用会长期保留管理权限的设备登录 UFI-TOOLS，开启高级功能，确认 Root Shell 可用。先保存热点原始配置和重要插件配置。
2. 在插件管理中导入 `.js`，保存并刷新。点击“UFI-Gate 网闸”。宿主所有插件合计最多 5 MiB，只导入匹配架构的一个包；若超出需清理不用的插件。不要同时安装多个 UFI-Gate 副本。
3. 点击“检测环境”，核对热点接口（例如 `wlan0` / `ap0`）与网关。点击“安装 / 更新服务”。只部署服务，此时不改网络准入。
4. 打开独立后台。安装器通过 URL fragment 传入初始化凭证（不作为 HTTP URL 查询参数发送）。设置管理账号和 8–72 字节、含字母数字的密码，当前管理设备被保留并默认信任。
5. 设置认证方式、上网账号、默认配额、页面文案和需要的推送。测试推送后查看运行日志。配额为 0 表示无限；提前限速阈值为 0 表示关闭提前限速。
6. 核对接口、标准和厂商加速处理，准备好 Root 恢复通道，在服务设置中勾选确认并开启认证。随后在 UFI-Tools 宿主 WiFi 管理中将热点设为 OPEN/NONE 并开启 AP 隔离，重新连接热点。SSID、加密与 AP 隔离由宿主统一管理，本插件不再代为修改。
7. **用第二台未信任设备完成下述真机验收后再向其他人开放。** 管理设备本身默认信任，不能用于验证未认证拦截。

后台支持多台管理员设备。在「设备管理」中设置或移除管理员权限，仍需使用管理员账号密码登录；至少保留一台管理员设备。管理员权限与联网授权独立，永久信任不会自动获得管理权限。后台 API 会核对当前热点设备身份，无法识别为管理员设备的 VPN / 代理请求也不能直接登录。

初始化凭证 20 分钟过期。点击安装器「重置初始化凭证」并确认后，会清空管理员账号、密码、管理员设备列表及后台登录会话，生成新的凭证。此操作要求服务正在运行，通过设备本地控制通道执行，不停服，不修改已获准设备的联网授权、配额和流量记录。随后可在任意连接此热点的设备上访问 `http://热点网关:8081/`，凭新凭证重新初始化；成功后，该设备成为新的管理员设备。未初始化期间仅额外开放 8081 初始化入口，宿主其他管理端口不会向所有访客开放。

## 配额口径

- **日**：北京时间 UTC+8，自然日 00:00 清零。
- **历史累计**：设备被记录以来的上行 + 下行。
- **认证会话**：新的认证会话建立后计数；有效会话内重复认证不会清零或续期。
- **周期**：以 Unix 纪元为锚点的 UTC+8 固定天数窗口；例如 7 天表示固定七天窗口，不等同于“周一开始的自然周”。本月统计按自然月单独记录。
- 达到限额后限制会锁存，跨日不会自动解除，符合“联系管理员解禁”的使用场景。
- **解除限制**保留历史流量，记录当前用量为新配额基线，给予新一轮额度并恢复会话；**重置流量**才清除该设备的全部统计。

## 独立设备限速

在「设备管理」中点击「一键限速」，填写 1–102400 KiB/s 的整数，分别限制该设备上传和下载速率。1024 KiB/s 约等于 8 Mbps。可以随时修改或取消，重启后保留。

独立限速不授予联网权限，不修改流量配额、不清零统计。与配额限速同时触发时取更低速率；封禁和配额断网仍优先。「取消独立限速」不会解除配额限制，「解除限制」和「重置流量」也不会取消独立限速。沿用 iptables hashlimit 丢包限速，实际速度和短时突发受设备固件、协议影响。

## 推送与第三方验证码

企业微信填完整机器人 Webhook。飞书可填机器人 Webhook 与签名密钥。通用 Webhook 接收 JSON：`title/content/request/allow_url/deny_url`，可选 Bearer Secret。SMTP 支持 465 SMTPS 和 587 等 STARTTLS 端口，使用宿主自带 curl，TLS 校验不跳过。凭据只在本地 0600 状态文件或短时临时配置文件中保存，不作为 curl argv 参数。

可选“认证页域名”会被本地 DNS 指向网关，用于第三方服务的域名登记；该域名不是自动注册的公网域名。服务商还可能要求 HTTPS 或特定浏览器环境，须按自己的账户策略验证；这个版本的门户 HTTP 服务不会自动提供 TLS 证书。hCaptcha / Turnstile 依赖域名随服务商配置变化，请按实际加载记录配置白名单，而不要直接添加大范围 CDN 白名单。

自定义验证 API 接收表单 `secret / response / sitekey`（可获取公网客户端时附加 `remoteip`），返回 JSON `{ "success": true }`。自定义前端脚本须实现：

```js
window.ufiGateCaptchaRender = function (element, {sitekey, callback}) {
  // 渲染你的验证控件，成功取得票据后：
  // callback(ticket)
}
```

私网客户端地址不会作为第三方接口的公网 `remoteip` 提交。第三方 Secret、SMTP 密码、签名密钥不会通过配置读取 API 回传；留空保留旧值，输入新值覆盖。若要彻底删除保留的密钥，可停服后从本地状态文件清理。

## 运行与紧急恢复

数据目录：`/data/ufi-gate`，0700；状态：`state.json`，0600；服务日志：`service.log`，supervisor 日志：`supervisor.log`。浏览器关闭不影响网络策略。

```sh
# UFI Root Shell / ADB su 执行：停止、清理规则、关闭认证并恢复标准 offload 设置
sh /data/ufi-gate/service.sh recover

# 启动或查看状态
sh /data/ufi-gate/service.sh start
sh /data/ufi-gate/service.sh status

# 卸载服务，保留状态/流量历史
sh /data/ufi-gate/service.sh uninstall
```

如二进制无法执行，可运行源码包内的 `emergency-recover.sh` 删除 UFIG_ 跳转。常规清理只移除本插件命名的链和跳转，不清空 Android 或其他插件的全局防火墙。通过网闸的转发流量会返回 Android 原有 FORWARD 规则继续接受检查，不覆盖宿主或其他插件的限制。开机接入在 `/sdcard/ufi_tools_boot.sh` 添加一行带 `ufi-gate-boot-v1` 标记的命令，停止/卸载只去掉这一行。

宿主保存“停用”或删除插件后，守护服务每 30 秒查询本机插件配置，成功确认后恢复网络并退出。若宿主接口改变/不可达，无法保证从宿主列表停用会被识别，请使用独立后台开关或 Root 恢复命令。重新启用插件后需在安装器启动服务，并在后台重新开启认证。

## 真机验收（当前待完成）

| 场景 | 检查 |
|---|---|
| 未认证 | HTTP 系统探测/普通 HTTP 跳门户；HTTPS、QUIC、直连 IP、手动 DNS、聊天/视频 APP 无外网连接 |

| 恢复 | 关闭认证、停止服务、宿主停用、卸载、模拟守护进程崩溃，其他插件规则与原后台仍可用 |
| 性能 | 常驻 RSS、CPU、电池消耗、热点休眠重启、规则更新时间；没有真机数值，不能宣称达到 PRD 的 <40 MB / <2 秒指标 |

## 构建与测试

```sh
go test -race ./...
go vet ./...
python3 build.py --go /path/to/go --out ./dist

# 在开发机本地运行 UI 与逻辑演示，不写系统防火墙
go build -buildvcs=false -o ufi-gate-demo .
./ufi-gate-demo --demo --dir ./demo-state

# 开发机安装 Playwright 浏览器后，运行自动 UI 测试（会自己启动 demo 服务）
node tests/ui-test.cjs
```

`--demo` 不做真实网络拦截，也不模拟运营商流量。逻辑测试使用注入的规则执行器核对规则优先级与恢复范围；不能替代真实内核/固件验收。

本次验证：21 项 Go 自动化测试及 race 检查、Go vet、页面 JS 语法和 Shell 语法检查；三个宽度（390/834/1440）共 30 个后台布局检查，账号认证、图形验证码、申请审批、封禁、解禁和停用的浏览器集成流程。没有保存用户凭据、真实访客信息或推送密钥到分发包中。

宿主接口按仓库 `http-server-version` 2026-10-11 读取内容适配，参考提交 `cf83b815efb114ed026f06dc90550845aafbfceb`。上游若改 Root Shell、上传接口或插件停用包装，请重新确认兼容性。
