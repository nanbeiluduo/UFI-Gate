# 门户页面设计器

从管理后台左侧「页面设计器」进入。仅管理员设备登录后可以保存和发布主题。

## 编辑与发布

1. 选择认证首页、等待审批、认证成功或访问受限页面。访问受限涵盖封禁、配额耗尽与网站访问限制，实际原因始终由服务显示。
2. 从简洁、品牌展示或公告模板开始，或直接添加组件。
3. 选择前置内容、后置内容或公共页脚区域，点击添加组件；电脑也可把组件拖到目标区域，并拖动现有组件调整同一区域内的顺序。手机使用上移／下移按钮。
4. 支持文本、图片、双列容器、链接按钮、公告、分隔线和留白。选择组件后设置文字、字号、颜色、对齐。容器支持内部组件编辑和排序；小屏自动单列。
5. 全局可设置主题色、背景色、认证卡片圆角。原有「门户外观」继续负责 Logo、认证标题等配置。
6. 保存草稿不会影响访客。发布需等待三秒确认，访客重新加载页面后生效。恢复上一版切换上一次发布状态；恢复默认保留草稿。

编辑器提供四种页面状态和不同宽度的示意预览，不会真实提交认证。真实账号、图形／第三方验证码和审批表单仍由原有认证逻辑生成。手机系统可能在联网成功后关闭认证窗口。

## 必需组件

认证组件位于固定的系统区域，不能删除、隐藏或覆盖。自定义组件只能出现在其前后；错误提示、限制原因、管理员登录／恢复入口仍保留。自定义主题不能包含 HTML、脚本、任意 CSS 或广告。

## 导入导出与图片

导出文件为 JSON，内含本地图片，可以跨设备分享。导入通过服务端校验后保存为草稿，发布前不会影响线上页面。导入会替换当前草稿，可撤销后重新保存。

- 每张图片限制 32 KiB、1024 × 1024，支持 PNG、JPEG、GIF；不接收 SVG 或外部图片 URL。
- 主题请求最大 1 MiB，所有页面和公共区块合计最多 80 个组件，容器层级受限。
- 链接按钮只接受 HTTP／HTTPS；访客未认证时，外部链接仍受原有准入策略限制。
- 文本作为纯文本显示，导入文件中的未知字段、组件和版本会被拒绝。
- 公共页脚在所有状态页复用。草稿在当前后台页面会话内保留，关闭前应保存；多人编辑冲突时需要重新加载页面再编辑。

## 数据与恢复

主题存放于 `/data/ufi-gate/portal-theme.json`，包含草稿、已发布主题、上一版和修订号。文件原子写入，服务更新保留状态目录。主题损坏时回退默认门户，不阻断原有认证。

现有配置备份接口不包含独立主题文件；请使用「导出主题」单独备份。恢复默认不修改认证、配额、设备权限、Logo 或网络配置。
