# 待发布：热点接口与网关检测、校验及修复

尚未指定版本号；本次不修改 1.1.9 版本常量、不创建标签、不发布 GitHub。

- 安装器与「检测环境」统一调用 Go 检测逻辑，展示运行、保存、安装引导配置，接口状态、IPv4/前缀、候选与推荐理由。
- 安装前验证接口存在、已启用、适合作为热点及地址归属；明确错误阻止安装，系统查询失败显示无法验证。已有状态继续保留，安装器输入不会静默覆盖它。
- 插件新增「修改热点接口与网关」及「查看配置修复结果」。无需进入 UFI-Gate 后台，支持停服设备；提供重检、取消和明确确认。
- 配置修复与安装/更新互斥；停止、最终状态备份、两文件事务写入、启动验证、中断恢复和失败回退。完成或成功回退后认证保持关闭，业务数据保留。
- 去除安装器 pkill 模糊进程清理，supervisor 按记录 PID 和具体命令识别进程。
- 管理员初始化识别失败时区分配置错误、MAC 未找到和系统查询失败；保持现有设备身份及后台权限校验。
- 未勾选服务设置确认项时，开启认证自动跳转并高亮该项，需要用户手动确认并保存。

需要替换对应架构 JS 插件和服务。操作、失败恢复及 F50 真机验收见 [网络配置修复说明](../NETWORK_REPAIR.md)。本地测试结果见交付包外附的验证报告；不宣称完成真机验收。
