# UFI-Gate v1.0.0-beta.1

首个开发测试版，为 Rooted ARM64 Android 随身 WiFi 提供 UFI-TOOLS 单文件插件、独立管理后台和网页认证门户。

## 下载

- `UFI-Gate-1.0.0-beta.1-arm64.js`：可导入的插件，内嵌静态 ARM64 服务。
- `UFI-Gate-1.0.0-beta.1-source.zip`：该发布提交的源码、依赖许可证、安装说明与测试记录。
- `build-info.json`：工具链、文件体积与哈希。
- `SHA256SUMS`：附件校验值。

## 首版功能

- 独立管理员账户、设备看板、流量统计与设备管理。
- 日 / 累计 / 会话 / 周期配额，提前限速，满额限速或断网，管理员解除限制。
- 账号、图形验证码、第三方人机验证与申请审批。
- 企业微信、飞书、通用 Webhook 与 SMTP 审批推送接口。
- 未认证 IPv4 拦截、HTTP 门户跳转、DNS 管理、IPv6 旁路阻断。
- 域名 / IPv4 黑白名单、警告页定制、手机与平板适配。
- 独立常驻服务、开机接入、卸载与紧急恢复。

## 验证状态

本机已完成 21 项 Go 测试及 race / vet 检查、网页与 Shell 语法检查、三种宽度共 30 个后台布局检查、认证及审批等浏览器流程，以及安装器负载校验。

**尚未完成实际随身 WiFi 的网络栈、厂商加速、性能和功耗验收，也未用真实密钥验证推送送达及第三方验证码服务。此 Release 标记为预发布版。**

## 安装与限制

需要 Root、ARM64 和 UFI-TOOLS `http-server-version` 设备端完整版。插件约 3.45 MiB，宿主全部插件总计限制 5 MiB。导入后保存、刷新，再打开“UFI-Gate 网闸”安装和初始化。

首次启用请保留 Root Shell / ADB 恢复通道，用另一台未信任设备验收。发生问题可执行：

```sh
sh /data/ufi-gate/service.sh recover
```

HTTPS / HSTS 不能透明重定向；未认证 HTTPS / APP 流量被阻断，门户通过系统联网检测或 HTTP 打开。域名黑白名单是 DNS / IPv4 级尽力过滤。启用期间热点 IPv6 被阻断。远程审批需要 VPN 或隧道可达地址。

完整说明见 [README](https://github.com/zhaosaojis-debug/UFI-Gate/blob/main/README.md) 和 [安装与管理指南](https://github.com/zhaosaojis-debug/UFI-Gate/blob/main/docs/INSTALL.md)。
