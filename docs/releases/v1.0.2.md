# UFI-Gate v1.0.2

真机补丁修复：解决中兴随身 WiFi 官方后台占用 8080 导致服务无法启动的问题，并新增管理员远程踢人能力。

## 修复

- **认证门户口从 8080 改为 8090**。中兴等设备的官方后台管理服务占用 8080（且绑在 IPv6 双栈上），Go 守护进程抢不到 8080 会 `log.Fatal` 整体退出，连带 8081 管理后台无法访问（表现为 `ERR_CONNECTION_REFUSED`）。现已将认证门户监听口、所有 iptables `REDIRECT --to-ports`、过滤器放行规则及前端门户跳转统一改为 8090；管理后台仍为 8081。
- 修正了安装时热点接口需手动核对的问题：设备桥接口为 `br0` 时不应保留默认的 `wlan0`。

## 新增

- **远程踢人下线**。在管理后台对某台设备执行「清除会话」或「封禁」时，除清会话外，守护进程会通过 hostapd 控制 socket（自动探测 `/data/vendor/wifi/hostapd/ctrl`、`/data/misc/wifi/hostapd`、`/var/run/hostapd`）向该 MAC 发送 `DEAUTH`，使其断开重连并重新触发认证页弹出。踢人失败仅记日志，不影响后台操作。

## 下载选择

- `UFI-Gate-1.0.2-arm32.js`：`armv7l` / `armv8l`，静态 Linux ARMv7 soft-float 服务。
- `UFI-Gate-1.0.2-arm64.js`：`aarch64` / `arm64`，静态 Linux ARM64 服务。
- `UFI-Gate-1.0.2-source.zip`：本版本源码。
- `build-info.json` / `SHA256SUMS`：两种架构的构建参数、大小及 SHA-256 校验值。

不要同时导入两个安装包。仍要求 Root、UFI-TOOLS 设备端完整版，以及所需的 iptables / ip6tables 内核模块。

## 更新

删除宿主中旧版 UFI-Gate 插件条目，导入对应架构的新包，保存并刷新。打开“UFI-Gate 网闸”，先检测环境，再安装 / 更新服务；随后打开独立后台。保留 `/data/ufi-gate` 状态目录以保留账户和流量历史。运行中升级会暂时恢复网络并关闭认证，完成后核对配置并重新开启。

## 验证边界

本版本已在中兴 MU3351 / V50（`armv8l`）真机完成：管理后台、认证下发、自动弹窗与远程踢人验证。其他品牌机型仍可能占用不同端口，门户/管理口后续版本将改为可配置。首次启用保留 Root Shell / ADB 恢复通道，用第二台未信任设备测试。

紧急恢复：`sh /data/ufi-gate/service.sh recover`。
