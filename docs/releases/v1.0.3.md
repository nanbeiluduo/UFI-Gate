# UFI-Gate v1.0.3

安装器界面瘦身：移除与宿主重复的热点改写功能，SSID、加密与 AP 隔离统一交回 UFI-Tools 原生 WiFi 管理。

## 调整

- **删除插件内「热点设为 OPEN」与「恢复热点配置」两个按钮。** 此前安装器会通过宿主 `setAccessPointInfo` 接口把当前活动热点改成 OPEN/NONE 并写死 `ApIsolate=1`，再把改前配置存到 `/data/ufi-gate/wifi-before.json` 供恢复。这条路径与 UFI-Tools 自带的 WiFi 管理重复，且在多热点/厂商定制固件上容易误操作。本版本起 SSID、加密方式、密码与 AP 隔离全部由你在 UFI-Tools 宿主 WiFi 页面自行设置，插件不再代为改写热点参数。
- 插件按钮重排为三组：
  - 安装类：检测环境 / 安装·更新服务 / 打开独立后台
  - 控制类：启动服务 / 停止并恢复网络
  - 运维类：重置初始化凭证 / 查看启动日志 / 卸载服务
- 卸载确认文案同步简化，不再提示"先使用恢复热点配置按钮还原"。
- `docs/INSTALL.md` 中相关边界说明与安装步骤改为引导用户在宿主 WiFi 管理中完成 OPEN/NONE 与 AP 隔离设置。

## 不变

- Go 守护进程、iptables 准入规则、认证门户（8090）、管理后台（8081）、远程踢人、配额与推送逻辑均与 1.0.2 完全一致。
- 仍要求你手动把热点设为 OPEN/NONE 并开启 AP 隔离——这是网页认证能工作的前提，只是设置位置从插件按钮挪回了宿主原生页面。
- `/data/ufi-gate` 状态目录、管理员账号与流量历史继续保留。

## 下载选择

- `UFI-Gate-1.0.3-arm32.js`：`armv7l` / `armv8l`，静态 Linux ARMv7 soft-float 服务。
- `UFI-Gate-1.0.3-arm64.js`：`aarch64` / `arm64`，静态 Linux ARM64 服务。
- `UFI-Gate-1.0.3-source.zip`：本版本源码。
- `build-info.json` / `SHA256SUMS`：两种架构的构建参数、大小及 SHA-256 校验值。

不要同时导入两个安装包。仍要求 Root、UFI-TOOLS 设备端完整版，以及所需的 iptables / ip6tables 内核模块。

## 更新

删除宿主中旧版 UFI-Gate 插件条目，导入对应架构的新包，保存并刷新。打开"UFI-Gate 网闸"，先检测环境，再安装 / 更新服务；随后打开独立后台。保留 `/data/ufi-gate` 状态目录以保留账户和流量历史。运行中升级会暂时恢复网络并关闭认证，完成后核对配置并重新开启。

如果你此前用过 1.0.2 或更早版本里"热点设为 OPEN"按钮改过热点，升级后请在 UFI-Tools 宿主 WiFi 页面自行确认加密方式与 AP 隔离是否符合预期——插件不再保留 `wifi-before.json` 自动恢复路径。

## 验证边界

本版本仅改动插件前端 UI 与文档，未触碰守护进程与防火墙规则。中兴 MU3351 / V50（`armv8l`）上的既有功能在同一份后端代码上回归验证通过；其他品牌机型仍需保留 Root Shell / ADB 恢复通道，并用第二台未信任设备测试。

紧急恢复：`sh /data/ufi-gate/service.sh recover`。
