# UFI-Gate v1.0.4

门户外观自定义：新增网站 Logo 与认证页 Logo 设置，可以用自己的图片替换默认图标。

## 新增

- **网站 Logo**：在管理后台「门户外观」中上传，显示于浏览器标签页、后台登录页和后台左侧品牌区域。
- **认证页 Logo**：独立设置访客认证页面顶部的图片，替换原来的 WiFi 图标。图片保持原始比例，支持透明背景。
- **上传预览与恢复默认**：选择图片后即可预览，点击「保存设置」后生效。两个 Logo 可以分别设置、分别恢复默认；恢复默认也需要保存。
- **本地保存**：图片随配置保存在设备中，不依赖外部图床，未认证、尚未联网的访客也能加载。配置备份会包含 Logo 图片。

## 图片要求

- 支持 PNG、JPG（JPEG）、GIF。
- 单张图片不超过 **32 KiB**，宽高均不超过 **1024 像素**。
- 建议使用小尺寸透明 PNG；网站图标建议使用正方形图片。
- 前端检查文件类型、大小和尺寸，服务端进一步校验图片实际格式、尺寸及是否可解码。

## 使用方法

1. 打开独立管理后台，进入「门户外观」。
2. 在「网站 Logo」或「认证页 Logo」中选择本地图片并查看预览。
3. 点击「保存设置」。
4. 打开认证页面，查看访客实际看到的 Logo；需要取消自定义图片时，点击对应的「恢复默认」并保存。

旧版配置无需迁移。未设置 Logo 时继续显示默认图标。

## 更新

本次涉及前端页面和 Go 服务，需要重新构建并安装插件；仅上传源码或刷新旧版页面不会启用新功能。

构建对应设备架构的新版安装包后，删除宿主中旧版 UFI-Gate 插件条目，导入新包，保存并刷新。打开「UFI-Gate 网闸」，先检测环境，再安装 / 更新服务，随后打开独立后台。

保留 `/data/ufi-gate` 状态目录以保留账户、配置和流量历史。运行中升级会暂时恢复网络并关闭认证，完成后核对配置并重新开启。
