# UFI-Gate v1.0.5

管理员管理与设备限速增强：支持不停服重置管理员、多台管理员设备，以及独立于流量配额的自定义限速。

## 新增与调整

- **重置管理员与初始化凭证**：插件菜单中的「重置初始化凭证」增加二次确认。确认后清除管理员账号、密码、管理员设备权限和后台登录会话，生成新的初始化凭证，有效期为 20 分钟，旧凭证失效。
- **保留已有联网状态**：重置通过设备本地控制通道执行，不停止服务，不修改已获准设备的联网授权、配额或流量记录。重置后，任意连接此热点的设备均可访问后台，凭新凭证重新初始化。
- **多台管理员设备**：后台「设备管理」新增「设为管理员设备」和「移除管理员权限」。管理员设备仍需账号密码登录；管理权限与联网授权独立，添加或移除管理权限不会改变设备的联网授权。
- **防止误删最后一台管理员设备**：后台至少保留一台管理员设备；需要清空全部管理员信息时，使用插件菜单中的凭证重置功能。移除当前设备的管理权限后，该设备将无法继续访问后台。
- **独立设备限速**：设备卡片新增「一键限速」，设置后可修改或取消。支持自定义 1–102400 KiB/s 的整数速率，分别限制上传和下载，设置在重启后保留。

## 限速与配额的关系

独立限速不授予联网权限，不修改配额，也不清零流量统计。与配额限速同时生效时，采用两者中更低的速率；设备封禁和配额断网仍优先。

- 「取消独立限速」只取消手动设置的速率限制，配额策略继续生效。
- 「解除限制」和「重置流量」不会取消独立限速。
- 1024 KiB/s 约等于 8 Mbps；填写的速率分别应用于上传和下载，并非两个方向合计。
- 沿用 iptables hashlimit 丢包限速，实际速度与短时突发受设备固件、协议影响。

## 使用方法

### 重置并重新初始化管理员

1. 确保服务正在运行，在插件菜单中点击「重置初始化凭证」。
2. 阅读弹窗说明并确认，保存返回的新凭证。
3. 使用任意连接此热点的设备访问 `http://热点网关:8081/`。
4. 在 20 分钟内输入新凭证，设置新的管理员账号和密码。初始化成功后，当前设备成为新的管理员设备。

未初始化期间仅额外开放 8081 初始化入口，宿主其他管理端口不会向所有访客开放。重置不会删除访客上网账号；已获准设备继续按原有授权期限和配额策略使用网络。

### 管理设备权限与速率

进入后台「设备管理」，在目标设备卡片中点击「设为管理员设备」或「移除管理员权限」，确认后生效。需要限制速率时，点击「一键限速」并输入速率；后续可通过「修改限速」或「取消独立限速」调整。

## 兼容与更新

旧版单一管理员设备配置会自动兼容为管理员设备列表，无需手动迁移。后台 API 会核对当前热点设备身份；无法识别为管理员设备的 VPN / 代理请求不能直接登录。

本次包含 Go 服务、插件菜单和后台页面更改，需重新构建并安装对应架构的新版插件。仅上传源码或刷新旧版页面不会启用新功能。

导入对应架构的新包，保存并刷新，打开「UFI-Gate 网闸」，先检测环境，再安装 / 更新服务。保留 `/data/ufi-gate` 状态目录以保留账户、配置和流量历史。安装升级会暂时恢复网络并关闭认证，完成后核对配置并重新开启；日常使用本版本的管理员重置功能无需停服。
