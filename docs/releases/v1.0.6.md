# UFI-Gate v1.0.6

默认品牌图标更新：内置蓝色 WiFi 盾牌 Logo，全新安装即可在网站和认证页面显示统一的品牌图片。

## 新增与调整

- **默认网站 Logo**：浏览器标签页、后台登录页和后台品牌区域默认使用新的蓝色 WiFi 盾牌图片。
- **默认认证页 Logo**：访客认证页面顶部默认显示同一张图片，替换原来的简单 WiFi 图标。
- **默认图预览**：后台「门户外观」中，未设置自定义 Logo 时直接显示内置图片预览。
- **恢复默认**：网站 Logo 和认证页 Logo 点击「恢复默认」并保存后，均恢复为这张内置图片。
- **随服务内置**：图片保存在 `web/default-logo.png`，构建时嵌入 Go 服务，无需外部图床，未认证、尚未联网的访客也能加载。

## 兼容与使用

全新安装无需额外设置，网站和认证页面自动使用新的默认 Logo。旧版配置未设置自定义 Logo 时，升级后也会使用新图片。

已上传的自定义 Logo 继续优先显示，不会被本次更新覆盖。网站 Logo 与认证页 Logo 仍可分别上传、分别恢复默认；上传图片的格式、大小和尺寸要求保持原有规则。

认证页面加载自定义 Logo 失败时，会回退显示内置默认图片。

## 更新

本次包含内置图片、Go 服务和前端页面调整，需要重新构建并安装对应架构的新版插件。仅上传源码或刷新旧版页面不会更新设备上的默认 Logo。

导入对应架构的新包，保存并刷新，打开「UFI-Gate 网闸」，先检测环境，再安装 / 更新服务。保留 `/data/ufi-gate` 状态目录以保留账户、配置和流量历史。运行中升级会暂时恢复网络并关闭认证，完成后核对配置并重新开启。
