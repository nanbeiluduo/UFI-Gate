# UFI-Gate v1.0.7

后台访问拦截增强：非管理员设备访问管理后台时直接关闭连接，不再加载后台页面或显示权限提示。

## 调整

- **连接入口检查**：管理员初始化完成后，服务在读取后台 HTTP 请求前核对设备身份，非管理员连接直接关闭，不返回后台页面。
- **覆盖整个后台**：首页、JavaScript、样式、Logo、后台 API 及 8081 端口上的审批入口均受保护。
- **不依赖认证开关**：即使关闭网络认证，后台连接权限检查仍然生效。认证开启时，原有热点 INPUT 防火墙规则继续优先拦截。
- **已有连接重新检查权限**：每次 HTTP 请求都会重新核对设备权限，避免设备被移除管理员权限后通过已有长连接继续访问后台。

## 访问表现

非管理员设备不再看到「此设备没有后台管理权限」的页面，而是无法加载后台。连接被服务关闭时，浏览器可能提示连接失败或连接被关闭；命中防火墙 DROP 规则时，可能表现为连接超时。具体错误文字由浏览器和网络环境决定。

管理员设备可以正常打开后台，仍需使用管理员账号密码登录。设备的联网授权与后台管理权限继续独立，获准上网或永久信任不代表具有后台访问权限。

## 初始化与审批

- 全新安装或重置管理员后，初始化入口保持开放，连接热点的设备可凭有效初始化凭证创建管理员。
- 初始化完成后，后台重新限制为管理员设备访问；初始化前建立的连接也必须通过后续权限检查。
- 非管理员设备无法打开 8081 端口上的审批链接，请使用管理员设备处理审批。

## 更新

本次更改涉及 Go 服务，需要重新构建并安装对应架构的新版插件。仅上传源码或刷新旧版后台页面不会启用新的连接拦截。

导入对应架构的新包，保存并刷新，打开「UFI-Gate 网闸」，先检测环境，再安装 / 更新服务。保留 `/data/ufi-gate` 状态目录以保留账户、管理员设备配置和流量历史。运行中升级会暂时恢复网络并关闭认证，完成后核对配置并重新开启。

## 验证边界

- 已通过连接测试，确认认证开关开启和关闭时，非管理员访问后台页面、资源、API 和审批入口均无法取得 HTTP 响应。
- 已验证重置后初始化页面可访问、初始化前建立的长连接无法绕过权限限制，以及管理员设备仍可正常加载登录页。
- 本地环境为 Windows。后端测试通过临时覆盖绕过 Linux 文件锁，排除依赖 Unix 文件权限的 `TestPersistenceAndPermissions` 后，其余测试通过；正式源码保留 Linux 文件锁逻辑。
- 已完成包含本次更改的 Linux ARM32 / ARM64 插件打包。
- 尚未完成设备端真机验证，目标设备上的防火墙拦截及浏览器实际提示仍需现场验收。
