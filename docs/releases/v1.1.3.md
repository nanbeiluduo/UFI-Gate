# UFI-Gate v1.1.3

修复「更新管理」页版本说明区域 Markdown 原文不渲染的问题，引入完整 Markdown 解析器与 HTML 消毒管道，标题、粗体、列表、代码块、表格等格式现在能正确显示。

## 问题

v1.1.2 及之前版本，后台「更新管理」页的"版本说明"区域直接以纯文本显示 GitHub Release Body，`#`、`##`、`-`、`**`、`` ` `` 等 Markdown 语法原样露出，排版全挤在一起。原因是前端用 `<pre>` + `textContent` 渲染，没有做 Markdown → HTML 转换。

## 改动

- **引入 marked.min.js（约 35KB）**：完整 GFM Markdown 解析器，支持标题、段落、有序/无序列表、嵌套列表、粗体/斜体、行内代码、代码块、引用、表格、链接。
- **引入 DOMPurify.min.js（约 21KB）**：对 marked 输出的 HTML 做消毒，过滤 `<script>`、`<iframe>`、`onerror` 等危险标签与属性，防止 release notes 中意外出现的可执行内容。
- **渲染链路**：GitHub API 返回的 Markdown 原文 → `marked.parse()` 转 HTML → `DOMPurify.sanitize()` 过滤 → `innerHTML` 渲染到版本说明容器。
- **容器从 `<pre>` 改为 `<div>`**，并补充 h3/h4/p/ul/li/code/pre 的间距样式，浅色/深色主题均适配。
- 两个 JS 文件随 `go:embed` 打包进二进制，不依赖外部 CDN，离线设备可用。

## 兼容性

- 不影响设备端更新流程：签名校验、SHA-256、镜像回退逻辑不变。
- 仅影响管理后台「更新管理」页的展示效果，其他页面（设备管理、审批中心等）未改动。
- 体积增量约 56KB，在 5 MiB 插件总上限内。
