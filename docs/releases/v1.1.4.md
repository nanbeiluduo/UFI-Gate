# UFI-Gate v1.1.4

修复安装器在残留更新进程卡住时无法安装的问题。点击「安装/修复」后，安装器会先强制结束所有残留的 ufi-gate 进程、清理中断的临时目录，再执行安装，不再卡在"另一个安装或更新任务正在运行"。

## 问题

v1.1.3 及之前，如果一次更新因网络超时等原因中断，updater 进程可能残留并持有文件锁。之后无论是在后台点"更新"还是重新用 JS 安装器安装，都会一直提示"另一个安装或更新任务正在运行"，只能手动 ADB 杀进程或重启设备才能恢复。

## 改动

- **安装器安装前自动清理**：在 `plugin.template.js` 的安装流程中，用户确认安装后、解压新二进制前，自动执行 `pkill -f ufi-gate` 结束所有残留进程，等待 2 秒确保文件锁释放，并清理 `/data/ufi-gate/update-stage-*` 临时目录。
- 锁机制本身不变：仍为 `flock(LOCK_EX|LOCK_NB)`，进程退出后内核自动释放锁，无需手动删 `update.lock` 文件。
- 仅影响 JS 安装器的前置步骤，Go 二进制、签名校验、镜像回退等逻辑均未改动。

## 兼容性

- 安装本来就会短暂停服，先杀进程再装不影响网络恢复流程。
- 已安装 v1.1.0~v1.1.3 的设备可直接用本版 JS 安装器覆盖修复。
