# UFI-Gate v1.1.5

管理后台左侧导航新增「关于」页面，集中展示当前版本、系统架构、运行时间、认证状态，并提供 GitHub 仓库、发布历史、问题反馈和 Telegram 联系方式入口。

## 新增

- **关于页面**：左侧导航最底部新增「关于」菜单项（圆形 info 图标）。
- **系统信息卡片**：实时显示当前版本号、设备架构（arm32 / arm64）、运行时长、认证服务状态。
- **项目资源链接**：GitHub 仓库、发布历史、问题反馈、Telegram 联系作者（@nanbeiluduo）。
- dashboard API 新增 `arch` 字段，供前端展示运行架构。

## 兼容性

- 纯前端展示页面，不影响设备准入、防火墙、更新等任何核心逻辑。
- 不涉及配置变更，升级后无需重新设置。
