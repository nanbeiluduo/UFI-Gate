# UFI-Gate v1.1.6

消息盒子新增清理操作：除原有的「全部已读」外，现在可以一键删除已读消息，或清空全部消息。

## 新增

- **删除已读**：消息盒子工具栏新增「删除已读」按钮，一键移除所有已看过的消息，未读消息保留。
- **清空全部**：消息盒子工具栏新增「清空全部」按钮，二次确认后删除所有消息（含未读），不可恢复。
- 后端新增 `POST /admin-api/notifications/delete`，支持 `{Read:true}` 删除已读与 `{All:true}` 清空全部。

## 兼容性

- 仅站内消息管理，不影响推送、审批、设备准入与防火墙逻辑。
- 不涉及配置变更，升级后无需重新设置。
