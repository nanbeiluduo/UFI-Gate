# UFI-Gate v1.1.7

新增门户管理员登录与离线恢复密钥。当管理员设备的 MAC 地址变化、被识别为新设备时，可通过认证门户恢复管理权限，避免所有管理员设备都无法访问后台。首次注册、重新初始化和忘记密码流程同步加入恢复密钥 TXT 下载确认。

## 新增

- **门户管理员登录**：认证门户新增「管理员登录」入口。使用 UFI-Gate 管理员账号密码验证成功后，当前连接设备自动加入管理员设备列表，并进入管理后台。无需先访问 UFI-TOOLS，也不依赖旧 MAC 仍可用。
- **保留后台访问限制**：未通过管理员验证的设备仍受原有后台访问限制。服务根据当前连接和热点邻居表识别设备 MAC，不接受浏览器自行指定 MAC。认证开启时，同步更新网关管理端口的防火墙放行规则，使当前设备恢复访问 UFI-Gate 和 UFI-TOOLS 的能力；UFI-TOOLS 自身的登录验证仍然有效。
- **忘记密码恢复**：在门户管理员登录页面勾选「忘记密码，使用恢复密钥」，输入有效密钥、新密码及确认密码，即可进入密码重置流程，不需要原管理员密码。
- **一次性恢复密钥**：恢复密钥由密码学随机源生成，包含 256 位随机数，以 `UFIG-` 加分组字符的形式保存在 TXT 中。设备仅持久化校验摘要，不在状态文件中保存密钥明文。
- **强制下载确认**：首次注册、重新初始化、恢复密码时，均须点击「下载恢复密钥 TXT」，确认文件已保存后才能完成流程。服务端同时检查下载步骤，不能仅跳过页面直接提交完成请求。

## 密码恢复与密钥轮换

连接热点后，打开 `http://热点网关:8090/`，点击「管理员登录」即可操作。

- **记得管理员密码**：使用原账号密码登录，自动登记当前设备的新 MAC。已有恢复密钥继续有效，不必因 MAC 变化而更换。
- **忘记管理员密码**：使用恢复密钥验证后，下载并确认保存新密钥。完成时，新密码与新密钥生效，旧密钥立即失效，原有后台登录会话全部注销。
- **中途退出**：在下载确认完成前刷新页面、退出或服务重启，不会完成注册或密码重置。密码恢复时，原密码和原恢复密钥仍然有效，可重新发起流程。

下载确认流程有效期为 10 分钟；初始化还受原临时凭证 20 分钟有效期限制。下载票据绑定当前设备 MAC、IP 和原管理员凭据，不能由另一设备使用。门户管理员验证加入全局限流，不能通过更换 MAC 或 IP 清除失败限制。

恢复密钥等同管理员恢复权限。任何连接到该热点且持有有效密钥的设备都可以重置密码，请离线妥善保存，勿分享或上传到 GitHub。浏览器无法证明文件已永久落盘，因此下载后仍需用户确认已保存；系统认证小窗口不支持下载时，请改用正常浏览器打开门户。

## 初始化与插件重置

首次安装继续使用插件提供的临时初始化凭证 `setup.token`，有效期为 20 分钟。输入管理员账号密码后，新增恢复密钥下载步骤；只有完成保存确认后，才正式创建管理员并使初始化凭证失效。

插件菜单「重置初始化凭证」在确认后：

1. 清除管理员账号、密码、管理员设备权限、后台会话、旧恢复密钥及未完成的恢复流程。
2. 保留设备记录、上网账号、流量、配额、已有联网授权和其他系统配置，不停止服务。
3. 生成新的临时初始化凭证并打开后台，重新执行管理员注册和恢复密钥下载流程。

如果浏览器拦截新窗口，可使用插件显示的后台地址和初始化凭证手动进入。

## 兼容与升级

- 已安装用户无需重置账号。升级后，已有管理员首次进入新版后台时，若尚未配置恢复密钥，会引导生成、下载并确认保存。MAC 已变化的设备也可从门户使用原管理员账号进入此流程。
- 管理员设备权限与联网授权继续独立。门户管理员登录不会自动解除封禁、清除配额或重置流量；旧管理员设备保留，可在后台单独移除。
- 本次包含 Go 服务、门户、管理后台及插件安装器修改。仅上传源码或刷新旧页面不会启用新功能，需要构建并安装新版服务。
- 已接入后台更新机制的用户可在 v1.1.7 正式发布后升级服务；要获得插件菜单重置后自动打开后台的行为，还需换用 v1.1.7 对应架构的 JS 插件。
- 保留 `/data/ufi-gate` 状态目录。安装或更新服务会短暂停服并关闭认证，完成后核对配置并手动开启认证；日常使用「重置初始化凭证」无需停服。
- 沿用现有 HTTP 部署，本次未新增 HTTPS，不能保证开放 WiFi 上管理员凭据的传输保密性。

## 验证范围

- 本地 Go 测试与 `go vet` 通过。新增测试覆盖下载门槛、设备绑定、密钥重放拒绝、持久化、过期、旧会话失效、限流、跨站请求拒绝、配置保护、旧账号迁移、失败回滚及设备数据保留。
- 管理员恢复、设备管理、更新管理和原有门户四组浏览器测试通过，覆盖 390、834、1440 三种宽度；原有门户回归包含账号认证、验证码、审批、封禁、解除限制及关闭认证。
- 已完成包含本次功能的 ARM32 / ARM64 本地构建，安装器 24 个用例通过，两种插件均低于 5 MiB 限制。
- CI 已加入恢复流程浏览器测试；本地 Windows 未执行 Linux race / QEMU，不能将现有工作流配置视为本次线上执行结果。
- 尚未完成实际随身 WiFi 验收。需在目标设备验证 MAC 变化后的两个后台访问限制、门户登录后的权限恢复、其他访客继续受限、手机 TXT 下载，以及重置后原有数据和联网状态保留。
