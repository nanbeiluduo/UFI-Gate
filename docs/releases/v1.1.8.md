# UFI-Gate v1.1.8

补全管理后台登录页的「忘记密码」入口，管理员可直接进入已有的恢复密钥重置流程，无需先手动打开认证门户。

## 调整

- **后台登录页新增入口**：已初始化的管理后台登录页，在登录按钮下方显示「忘记密码？使用恢复密钥重置」。
- **直接进入密码恢复**：点击后跳转到同一设备的 8090 门户管理员页面，并自动勾选「忘记密码，使用恢复密钥」，直接显示恢复密钥、新密码及确认密码输入框。
- **沿用现有恢复流程**：验证有效密钥后，仍须下载新的恢复密钥 TXT 并确认保存，才能完成密码重置；完成后旧密钥失效，旧后台会话注销。
- **初始化入口保持原有流程**：尚未创建管理员时，继续使用临时初始化凭证注册，不显示忘记密码入口。

## 兼容与升级

本次修改前端入口，不改变管理员设备访问限制、密钥校验、设备数据、配额及防火墙策略。非管理员设备仍可从认证门户的管理员登录入口进行验证或恢复。

网页资源嵌入 Go 服务，需要更新到 v1.1.8 服务后生效；仅刷新旧服务页面不会获得新入口。已有管理员账号及恢复密钥继续有效，无需重新初始化。

保留 `/data/ufi-gate` 状态目录。服务更新完成后，按原有流程检查设置并手动开启认证。

## 验证

- JavaScript 语法检查。
- 浏览器回归覆盖初始化页不显示忘记密码、后台登录页跳转并自动选择恢复方式、新密钥下载确认、密码重置、旧密码与旧密钥拒绝，以及三种屏幕宽度。
- 本次未进行真实随身 WiFi 设备验收。

详细操作见 [管理员恢复指南](https://github.com/nanbeiluduo/UFI-Gate/blob/main/docs/ADMIN_RECOVERY.md)。
