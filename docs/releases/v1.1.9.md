# UFI-Gate v1.1.9

新增用户自配的远程审批入口与测试消息，支持通过自备 HTTPS 穿透服务在外网审批；修复插件菜单输入框文字不清晰，并增加使用教程按钮。

## 远程审批

- 管理后台「消息推送」新增远程审批设置：启用开关、HTTPS 公网地址及本机端口，默认关闭。
- 独立服务仅监听 `127.0.0.1`，默认端口 8091，供同机穿透客户端转发。只开放审批页面、专用测试及样式资源；8081 后台继续限制管理员设备访问。
- 设置保存后立即生效，端口冲突时保留原设置；停止远程审批关闭监听。启动时端口异常不会阻止主服务运行，可在日志中查看并修改设置。
- 复用正式审批签名、有效期和单次处理规则，GET 不执行审批，POST 确认后才处理；补充限流、跨站来源检查及禁止缓存、禁止传递 Referer 的响应策略。
- 新增「发送远程审批测试」：管理员用手机流量打开消息并确认，验证公网连接。5 分钟有效，不会放行任何设备；重新生成或重启后旧测试链接失效。
- 项目不提供、也不内置公共穿透服务。用户自行选择免费或付费方案，承担相应服务器、域名和服务费用。填写 URL 不会自动建立隧道。

## 插件菜单

- 为热点接口、IPv4 网关输入框明确设置深色文字、WebKit 文字填充、光标和浅色背景，避免宿主深色主题将文字覆盖成白色。
- 增加「使用教程」按钮，新窗口打开仓库的 `docs/INSTALL.md`；同时显示可复制的教程地址。

## 升级

更新服务后可使用远程审批。插件菜单的颜色修复与教程按钮需要另外替换 v1.1.9 对应架构的 JS 插件；后台更新不会修改 UFI-TOOLS 保存的插件代码。

原有局域网审批配置保持兼容。不要删除 `/data/ufi-gate`；服务升级完成后检查配置并手动开启认证。新启用远程审批时，请将隧道指向独立审批端口，不要将 8081 或 Root Shell 暴露到公网。

配置及排查见 [远程审批指南](https://github.com/nanbeiluduo/UFI-Gate/blob/main/docs/REMOTE_APPROVAL.md)。

- 新增远程审批浏览器测试通过，覆盖设置校验、保存与刷新、停用、390/834/1440 三种宽度、宿主白色文字覆盖场景及教程链接；管理员管理、密码恢复、更新管理及原有门户浏览器回归通过，原有门户完成 30 项页面宽度检查，浏览器错误为 0。

- 真实随身 WiFi、真实飞书推送及第三方穿透连通性仍需设备端验收。
