# UFI-Gate v1.2.0

新增独立后台服务更新、全局悬浮消息盒子及分类推送，安装器增加防降级、健康检查和失败恢复。

## 新增功能

- **更新管理**：手动检查 GitHub 最新正式 Release，查看版本说明与下载入口，确认后更新匹配架构的服务。可选每日自动检查，只提醒、不自动安装。
- **安全校验**：Ed25519 签名清单、更新包大小与 SHA-256 校验、架构/版本/协议检查，拒绝降级与无签名更新。
- **安装与恢复**：两个更新入口共用安装锁，独立进程完成备份、替换及启动健康检查；失败尝试回退，中断记录用于后续启动恢复。保留管理员、设备、配置、图片、配额及流量。
- **稳定安装器**：每次发布仍生成新版 JS 供首次安装；已安装用户后续使用独立后台升级。新版安装器拒绝用旧内嵌服务覆盖较新本地服务，同版本修复需确认。
- **全局消息盒子**：所有已登录后台页面显示悬浮按钮和未读数量，支持筛选、全部已读、跳转处理及状态持久化。
- **分类推送**：审批、认证异常、配额预警/耗尽、服务异常、管理员变更、版本发现及更新结果统一进入站内消息，可按类型关联原有推送通道；提供去重与有限次重试。
- **自动构建**：同时生成 ARM32/ARM64 安装器 JS、服务更新包、签名清单、构建信息与校验文件。

## 升级说明

v1.0.9 及更早版本需要先导入 v1.2.0 新版 JS 并安装一次，之后才能使用后台一键更新。旧 JS 本身不会自动获得防降级保护，请替换旧插件条目并刷新页面。

安装和更新会短暂停服并关闭认证。完成后重新登录、核对设置，再手动开启认证；不要删除 `/data/ufi-gate`。首次安装尚无旧服务时，安装失败无法回退到不存在的旧版本，可查看日志后修复安装。


## 验证

本地验证覆盖 Go 逻辑、版本比较、签名与篡改拒绝、更新包路径边界、安装成功/失败恢复及状态保留；安装器覆盖 Root、架构、防降级、修复确认及暂存部署。浏览器检查覆盖全局通知、已读持久化、推送偏好、更新确认、说明转义和三种屏幕宽度，并回归设备限速、管理员权限与重置流程。
