# UFI-Gate v1.2.2

优化管理后台的页面内确认弹窗与响应式布局，修复小屏、手机和低高度窗口中侧栏菜单及退出登录按钮难以完整访问的问题。

## 页面内确认与倒计时

- 开启／关闭认证、管理员设备权限变更、删除设备、封禁、信任、清除会话、重置流量、清理审批、删除账号、清空消息和安装更新等原有浏览器确认框，统一改为页面内弹窗。
- 二次确认按钮等待 **3 秒**后才可点击，倒计时结束不会自动执行。取消、Esc 或点击确认弹窗外部均不提交操作；重新打开会重新计时。
- 删除已读消息和提交审批也加入二次确认。审批取消确认后保留已填写的处理备注。
- 普通保存与结果提示不强制等待。表单提交期间禁用保存按钮，避免重复提交。
- 消息盒子内可以正常打开确认弹窗；关闭确认后返回原界面。确认文本按纯文本展示，支持键盘焦点与取消操作。
- 保留 v1.2.1 的开启认证要求：新老用户均需本次勾选「已核对接口、加速设置，并准备好 Root 恢复通道」。未满足时先跳转服务设置并聚焦、高亮；有未保存配置时先保存，再进入开启认证的倒计时确认。

3 秒等待是页面交互保护，不替代服务端登录、管理员设备权限、来源及开启认证确认校验。

## 自适应布局

- 侧栏采用顶部标识、中间可滚动导航、底部账号与退出按钮三个区域。导航超出屏幕高度时独立滚动，退出登录保持在可视区域内。
- 使用动态视口高度并保留传统视口回退，加入手机底部安全区间距与窄横屏布局。
- 手机导航增加关闭按钮、遮罩、Esc 关闭和键盘焦点约束；打开时锁定背景滚动，选择菜单后收起。
- 调整窄屏顶部操作区、卡片列数、长文本换行、触摸按钮高度和关于页面布局。版本说明中的宽表格在自身区域横向滚动。
- 长表单弹窗内部滚动，底部操作区保持可触达；弹窗限制在可视高度内。消息按钮与普通提示错开，减少遮挡。
- 保留浅色／深色主题，补充可见键盘焦点并尊重系统减少动画偏好。

## 升级说明

本次变更在服务内嵌后台页面中生效。已有用户更新服务后请刷新后台页面，无需删除状态目录、重新初始化管理员或重新配置热点。原有业务数据、认证策略及非管理员访问限制不变。

新安装可使用对应架构的 v1.2.2 安装包。插件菜单本身未改动，本次页面内倒计时适用于独立管理后台；宿主插件的 Root 操作确认仍使用原有流程。服务更新沿用既有停服和认证关闭行为，更新后应检查配置，再手动开启认证。

README 的版本与发布记录由现有发布工作流更新，本次不手动改写。仓库源码版本已设为 `1.2.2`，本地交付不代表已经上传或发布。
