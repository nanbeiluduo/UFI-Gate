# UFI-Gate v1.2.3

新增门户页面设计器，让管理员可视化美化认证首页、等待审批、认证成功与访问受限页面。本版不包含广告功能。

## 新增

- 三栏编辑器、组件添加与拖拽排序、手机上下移动、容器内部编辑、撤销与重做。
- 文本、图片、双列容器、链接按钮、公告、分隔线、留白；字号、文字颜色、对齐、主题色、背景与卡片圆角设置。
- 简洁、品牌展示、公告模板，以及多个页面共用的公共页脚。
- 四种状态示意与多宽度预览；草稿保存、确认发布、恢复上一版和恢复默认。
- 含图片的 JSON 主题导入导出，导入前服务端校验，修订号避免多窗口覆盖。

## 兼容与保护

- 原有认证表单、错误提示、真实状态和管理员恢复入口保持在受保护区域，不能被自定义配置删除或覆盖。
- 继续使用原有管理员设备、登录会话与来源校验。拒绝任意 HTML／JS／CSS、未知组件、超限图片与无效链接。
- 主题独立保存在状态目录，草稿不公开。默认未发布主题时保持原门户；损坏主题回退默认。
- 不改变认证、配额、防火墙、服务更新和热点配置逻辑。无需重新初始化或删除设备状态。
- CI 与发布流程新增设计器脚本语法和浏览器回归，保留原有签名、安装器校验与双架构 QEMU 流程。

## 升级

更新服务后刷新管理后台，从左侧「页面设计器」进入。插件安装与后台更新继续采用原有流程；升级后按原有要求核对配置并手动开启认证。主题与图片随服务状态保留，不增加安装器运行时依赖。

使用说明、数据备份与限制见 [门户页面设计器](../PORTAL_DESIGNER.md)。现有配置备份不包含独立主题文件，请单独导出主题。

## 验证边界

本地验证记录随增量交付包附带。Windows 本地测试、浏览器模拟尺寸和交叉编译不代替 Android 真机、实际验证码平台、Linux race 或 QEMU 验收；GitHub Actions 需要上传后运行。真实设备重点检查认证小窗口、软键盘、图片加载、各认证方式和成功后窗口关闭行为。

## 本地验证结果

- Windows Go 1.24.2 完整 `go test -mod=vendor ./...`、`go vet -mod=vendor ./...` 通过。
- 新增服务端主题格式／危险链接／图片／组件数量校验、草稿隔离、发布、修订冲突、回退、默认恢复和损坏回退测试。
- 设计器浏览器回归通过：拖入组件、文本安全、四种状态、320／390／768／1440 宽度、容器编辑、撤销重做、导入导出、发布及恢复默认。
- 原有门户认证（账号、验证码、审批、封禁与恢复）、网络修复、设备管理、服务更新、管理员恢复、远程审批回归通过。
- 原有后台 144 项页面／视口检查及三秒确认交互通过。
- ARM32 与 ARM64 安装器分别为 4,169,794 和 3,986,634 字节；宿主存储检查及 24 项安装器验证通过。
- 本地安装包未注入正式签名密钥；正式发布继续由 GitHub Actions 使用既有密钥签名。
