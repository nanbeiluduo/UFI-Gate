# UFI-Gate v1.1.2

设备管理新增「删除记录」按钮，用于彻底清除某台设备的连接历史；下次它再接入 WiFi 时，将作为全新访客重新识别。

## 新增功能

- **删除设备记录**：在「设备管理」每张设备卡片的操作区新增红色「删除记录」按钮。点击并确认后，该设备的 MAC、IP、备注、信任状态、封禁状态、配额与流量统计从后台移除，防火墙规则经一次 reconcile 后该 MAC 回到未认证默认拒绝状态。
- **重新识别机制**：删除后若同一台设备再次接入 WiFi 并被邻居表/DHCP 扫描到，会以全新访客身份重新出现在列表中——无永久信任、无授权会话、无历史流量，需要重新完成认证流程。
- **管理员设备保护**：若被删除的 MAC 在管理员设备列表中，删除记录不会清除管理员权限；确认对话框会明确提示，需单独走「移除管理员权限」才能取消后台访问能力。这避免了管理员误删自己后无法登录后台。

## 使用场景

- 访客离开后希望彻底清除其历史记录，避免旧设备 MAC 残留占用列表。
- 测试设备反复接入时，需要从"干净状态"重新走一遍认证流程。
- 设备备注或配额设置混乱，想让它重新走一次标准准入流程。

## 注意

- 删除记录不会主动断开该设备当前的 WiFi 连接；它只是清除后台数据，下次扫描时重新创建。若设备正在联网，删除后到下一次采样窗口（约 5 秒）之间，它可能仍然在线。
- 若该设备处于"永久信任"状态，删除记录即等同于取消信任；若想保留信任但清除流量，请使用原有的「重置流量」。
- 本次发版同时由 CI 自动维护 `main.go` 版本常量与 README 版本记录，无需手动改源码版本号。
