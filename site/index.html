装上之后，热点还是开放的

连上 Wi-Fi 的人会先看到认证页。通过之后才放行。管理后台只对管理员设备开放，别人连页面都拿不到。

门户认证

账号密码、本地图形验证码、hCaptcha / Turnstile，以及管理员审批，可以同时打开，由访客自己选。

设备准入

按 MAC 识别。放行、封禁、清除会话、永久信任、备注，以及多台管理员设备。管理员权限和上网权限是分开的。

流量配额

自然日、历史累计、单次会话、固定周期。可以提前限速，满额后断网或继续限速，也可以给单台设备单独限速。

审批推送

企业微信、飞书、通用 Webhook 或邮件。外网审批走你自己的 HTTPS 隧道，转到本机 127.0.0.1。

网址规则

域名和 IPv4 的黑白名单。白名单可以免认证；黑名单优先。未认证时，名单之外的访问会被送回门户。

门户外观

Logo、标题、欢迎语、超限提示和主题色。页面设计器可以编排认证首页、等待、成功和受限四种状态。

独立后台

默认开在 8081，避开设备官方后台常用的 8080。不是管理员设备的连接会被直接关掉。

出事能恢复

管理员 MAC 变了可以用门户登录找回。忘记密码用离线恢复密钥。网络被规则拦住时，有紧急恢复脚本。

从导入到放行

热点的名字和加密仍然在 UFI-TOOLS 里设置。这个插件负责认证和准入，不替你改 SSID。

01

导入安装包

按 uname -m 选择 arm64 或 arm32 的 .js，在插件管理里导入、保存并刷新。

02

安装服务

打开「UFI-Gate 网闸」，先检测环境，核对热点接口和网关，再安装服务。

03

初始化后台

用管理员设备打开 http://网关:8081，创建账号，然后配置认证方式、配额和推送。

04

用第二台设备验收

热点保持开放。未受信任的设备应先看到 8090 上的认证页，通过之后才能上网。

没有设备，也可以把流程走一遍

在线体验在浏览器里模拟手机、平板、电脑上的认证门户，以及 8081 管理后台。可以改认证方式、白名单和配额，再让一台手机连上热点、提交审批、在后台通过，并看到用量变化。数据只留在这台浏览器里。

它听哪些端口

端口用途
8090访客认证门户。刻意避开很多设备官方后台占用的 8080。
8081管理后台。只有管理员设备的 MAC 能连上。
8091可选的远程审批入口，只听 127.0.0.1，端口可以改。
5354 / 67本地 DNS 应答和 DHCP。

需要已 Root 的 ARM32 或 ARM64 Android 随身 WiFi、UFI-TOOLS 设备端完整版，以及 iptables / ip6tables。HTTPS 不能在没有证书警告的情况下被透明转到认证页。
