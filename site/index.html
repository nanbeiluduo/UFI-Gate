热点开着，规则在你这边

插件跑在随身 WiFi 上，后台和认证页都由它自己提供，不依赖额外的云服务。

网页认证

上网账号、本地图形验证码、hCaptcha、Turnstile 或自定义验证接口，也可以改成管理员审批。

设备准入

按 MAC 识别设备。放行、封禁、清除会话、永久信任，管理员设备可以有多台，且与联网授权分开。

流量配额

自然日、历史累计、单次会话和固定周期可以叠加。提前限速，满额后断网或限速，由管理员解除。

审批推送

企业微信、飞书、通用 Webhook 和邮件。外网审批走你自己的 HTTPS 隧道，项目不提供穿透服务器。

独立后台

默认开在 8081。设备看板、实时速率、用量排行和日志都在同一套浅色 / 深色界面里。

门户设计器

分别布置认证首页、等待审批、认证成功和访问受限。认证表单留在固定区域，不能被盖住。

访问策略

域名和 IPv4 黑白名单。白名单可以免认证，黑名单优先。也可以换掉认证页上的 Logo 和文案。

客户端隔离

认证开启后，热点内设备默认不能互访。访问网关后台和外网仍按准入规则放行。

从导入到放行

安装包是单个 .js，里面已经带好静态守护程序。完整步骤在安装指南里。

  1. 01

    选对架构

    在 Root Shell 运行 uname -m。aarch64 用 ARM64，armv7l 和 armv8l 用 ARM32。

  2. 02

    导入并安装

    在 UFI-TOOLS 插件管理里导入 .js，检测环境，核对热点接口和网关，再安装服务。

  3. 03

    配置后台

    打开 http://网关:8081，创建管理员，设置认证方式、配额和推送。默认门户在 8090。

  4. 04

    用第二台设备验收

    管理设备本身是受信任的。换一台未受信任的设备连上开放热点，走完认证再给访客用。

在线体验

不用设备，也能把认证走一遍

在手机、平板、电脑和管理后台之间切换。改认证方式、配额和黑白名单，再模拟一台手机连上热点，看认证页、审批和用量如何变化。数据只留在这台浏览器里。

端口

端口用途
8090访客认证门户。避开设备官方后台常用的 8080。
8081管理后台。初始化完成后只允许管理员设备访问。
8091可选的远程审批入口，只监听 127.0.0.1。
5354本地 DNS 应答，把探测引向门户。

使用前需要知道

  • 需要已 root 的 ARM32 或 ARM64 Android 随身 WiFi，以及 UFI-TOOLS 设备端完整版。
  • 未认证的 HTTPS 不能无证书警告地跳进门户。认证页来自系统的“登录网络”、普通 HTTP，或你手动打开门户。
  • 流量大约每 5 秒采样一次，包含协议开销，不是运营商账单。
  • 远程审批要自己准备 HTTPS 隧道。不要把 8081 后台或 Root Shell 暴露到公网。
